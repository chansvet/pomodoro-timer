# 뽀모도로 타이머

베이지-핑크 톤의 미니멀 뽀모도로 타이머. HTML 파일 하나로 동작하며 설치·빌드·인터넷 연결이 필요 없습니다.

## 쓰는 법

[여기서 바로 실행](https://chansvet.github.io/pomodoro-timer/) 하거나, `index.html`을 내려받아 브라우저로 열면 됩니다.

## 기능

- **60분 다이얼** — 실물 타이머처럼 한 바퀴가 60분. 남은 시간만큼 파이가 채워집니다
- **돌려서 시간 맞추기** — 바늘 끝 손잡이를 잡고 돌리거나 다이얼 아무 곳이나 누르면 1분 단위로 설정됩니다. 실행 중에는 실수로 바뀌지 않도록 잠깁니다
- **자동 순환** — 집중 → 짧은 휴식, 설정한 횟수를 채우면 긴 휴식. 휴식 중에는 색이 차분한 토프로 바뀝니다
- **하루 기록** — 날짜별 집중 횟수와 시간을 쌓아 최근 7일 그래프로 보여줍니다. 끝까지 채운 세션만 횟수로 세고, 중간에 건너뛰면 시간만 반영됩니다
- **화면 꺼짐 방지** — 켜두면 타이머가 도는 동안 휴대폰 화면이 꺼지지 않습니다 (Wake Lock 지원 브라우저)
- **이어서 하기** — 앱이 꺼지거나 새로고침돼도 돌아가던 타이머가 남은 시간 그대로 복구됩니다
- **알림음** — 세션이 끝나면 부드러운 3음 알림
- 남은 시간이 브라우저 탭 제목에 표시되고, 스페이스바로 시작/정지
- 설정(기본 25/5/15분, 4회)은 브라우저에 저장됩니다

종료 시각을 기준으로 계산하기 때문에 탭을 백그라운드에 두어도 시간이 밀리지 않습니다.

- **기기 간 동기화** — 기록 패널에서 이메일로 로그인하면 폰과 컴퓨터가 같은 기록을 공유합니다

설정은 그 브라우저 안에만 저장됩니다. 기록은 로그인하지 않으면 마찬가지로 그 브라우저 안에만 남습니다.

## 동기화

[Supabase](https://supabase.com)를 씁니다. 라이브러리 없이 `fetch`로 REST API만 호출하므로 앱은 여전히 파일 하나입니다.

- 로그인은 매직링크 방식 — 이메일로 온 링크를 누르면 그 기기가 연결됩니다
- 같은 날짜가 양쪽에 있으면 **큰 값**을 남깁니다. 횟수와 시간은 줄어들 일이 없으니 어느 기기의 기록도 사라지지 않습니다
- 인터넷이 없거나 로그인하지 않았으면 조용히 넘어가고 로컬에만 기록합니다
- 행 단위 보안(RLS)이 걸려 있어 본인 기록만 읽고 쓸 수 있습니다 — 스키마는 `supabase.sql` 참고

코드에 들어 있는 `publishable key`는 원래 웹페이지에 넣으라고 만들어진 공개용 키라 노출돼도 안전합니다.

## 휴대폰에서 앱처럼 쓰기

사파리로 위 주소를 연 뒤 공유 → `홈 화면에 추가`. 전체화면으로 실행되고, 사파리가 탭을 정리해도 잘 꺼지지 않습니다.
